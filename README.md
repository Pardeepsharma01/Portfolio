# 🚀 Pardeep Sharma Portfolio

A modern, responsive, and animated personal portfolio website built with **Next.js, Tailwind CSS, and Framer Motion**.
Designed to showcase projects, skills, and experience with a clean UI and smooth user interactions.

---

## ✨ Features

* ⚡ Modern UI with dark + gradient theme
* 🎨 Smooth animations using Framer Motion
* 📱 Fully responsive (mobile, tablet, desktop)
* 🧭 Interactive navigation with mobile drawer
* 💼 Featured projects showcase
* 📊 Skills & experience sections
* 📬 Contact form UI
* 🔗 Social media integration (GitHub, LinkedIn, Twitter)
* ⏳ Custom animated loader on startup

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Fonts:** Geist (via next/font)

---


## 🚀 Getting Started

First, clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to see the result.

---



## 🌐 Deployment

The easiest way to deploy is using **Vercel**:

```bash
npm run build
npm start
```

Or deploy directly:

* Vercel (recommended)
* Netlify
* Firebase Hosting
